# LUMIA ML

## Overview
LUMIA ML implements Module 7 of Project LUMIA: the deep learning Real/Bogus classification system. Operating as a pure PyTorch inference pipeline, it evaluates 3-channel cutout triplets `(Science, Reference, Difference)` generated by image processing to distinguish genuine moving solar system objects from optical artifacts, subtraction residuals, diffraction spikes, and cosmic rays.

## Interface
- `RealBogusClassifier`: High-level inference engine handling mini-batch inference, device placement, checkpoint loading, and detection score attachment.
- `RealBogusNet`: Deep convolutional neural network architecture with 3-channel inputs, residual feature blocks, and sigmoid output probability.
- `TwoStreamAdaptationHead`: Cross-survey adaptation head combining spatial 2D CNN (Stream A) and temporal flux series MLP (Stream B) without violating the AST physics firewall.
- `CNNClassifierConfig`: Validated Pydantic configuration schema specifying model architecture, stamp size (31 or 51), inference batch size, decision threshold, and checkpoint paths.
- `CutoutClassificationBatchResult`: Immutable batch contract containing validated `ClassificationResult` entries, partition lists (`accepted_candidate_ids`, `rejected_candidate_ids`), and model provenance.
- `preprocess_triplets`: Channel-wise median and Median Absolute Deviation (MAD) robust scaling and clipping pipeline.
- `attach_classifications_to_detections`: Utility that mutates detection candidate lists by injecting classification scores and model versions.
- `InferenceMemoryError`: Specialized exception raised when CUDA out-of-memory occurs during batched inference.

## Invariants
- Input tensors must have shape `(B, 3, stamp_size, stamp_size)` with float32 or float64 elements and zero `NaN` or infinite values.
- `CutoutClassificationBatchResult`: Candidates are strictly partitioned into `accepted_candidate_ids` (`is_real=True`) and `rejected_candidate_ids` (`is_real=False`) according to `decision_threshold`.
- All `ClassificationResult` instances within a batch must report the exact same `model_version`.
- No database, network, or filesystem persistence operations are permitted within this package.

## Side Effects
- Loads PyTorch model weight checkpoints from disk when `checkpoint_path` is configured.
- Allocates CPU and CUDA tensor memory for batch execution.
- Configures deterministic RNG seeds and cuDNN settings via `LUMIA.core.runtime.configure_deterministic_torch`.
